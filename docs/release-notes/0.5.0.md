- **Pictures**: JPEG, PNG, GIF, WebP, HEIC, TIFF and more open read-only in a viewer, with animated GIF, WebP and APNG playing. ⌘+ and ⌘− zoom, ⌘0 shows the actual size and a double-click fits it to the window.
- **Videos and sounds**: MPEG-4, QuickTime, MPEG and whatever else macOS plays open in the system's player. Space plays and pauses.
- **Archives**: a zip, tar or tar.gz shows what it holds as a tree of folders and files, with each one's size unpacked. Nothing is unpacked to show it.
- **SVG preview**: an SVG opens on its picture, and the Text / Preview switch (⌃⌘P) shows its text to edit.
- The status bar says what a picture, video or archive is, such as its size, length or number of files.
- Escape now closes Settings, Keyboard Shortcuts and Command Line Tool.
