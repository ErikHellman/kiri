- **Reopen at launch**: started without a file or folder, Kiri opens the last one it showed instead of an empty editor, a folder with the file that was in front. Settings ▸ Editor ▸ Reopen at launch turns it off.
- **Recent folders**: File ▸ Open Recent lists the last five files and folders, and an empty editor shows them under its getting-started lines. The command palette finds recent folders too.
