- **Large files**: a file of 50 MB or more, even a log of many GB, opens read-only, after asking, in a viewer that opens at once and scrolls smoothly whatever its size. Find searches the whole file on every core, and **Only matching lines** in the find bar shows just the lines with a match.
- **Live logs**: a large file that is still being written is followed as it grows, as `tail -f` does, and output piped into `kiri -` that goes on (`adb logcat | kiri -`) is followed live in the same viewer.
- **Markdown preview** (the Text / Preview switch in the top bar, View ▸ Markdown Preview or ⌃⌘P): see a Markdown file rendered in the theme's colors, with GitHub tables, task lists and alerts, front matter as a table and Mermaid diagrams. Switching keeps your place both ways.
- **Command Line Tool** (Help ▸ Command Line Tool): every option of the `kiri` command with examples to copy, and Install… if it isn't installed yet.
