- **Find in the sidebar**: with the folder sidebar focused (⇧⌘E), ⌘F finds a file or folder by name anywhere in the folder, opening closed folders to show it. ⌘G and ⇧⌘G go to the next and previous match.
- **What's new**: after an update, Kiri shows what changed once, in the first editor. Turn it off with the box in the notice or in Settings ▸ Updates, and find it again in Help ▸ What's New in Kiri.
- **Remember position**: reopening a file returns to where you left it, including after relaunch.
