- **Send Feedback** (Help ▸ Send Feedback…): tell us what's not working or what you'd like to see, anonymously. You can attach a screenshot of the Kiri window, off until you turn it on and shown to you before it's sent.
- **Crash reports**: when Kiri crashes or stops responding, an anonymous report goes out so it can be fixed, and the next launch asks what happened.
- **Usage analytics**: anonymous counts of which features, settings and languages are used. Never file names, paths or text.
- **Settings ▸ Privacy** has a switch for crash reports and one for analytics, and a link to what Kiri collects: https://kiri.hellsoft.se/privacy.html
- Settings scrolls on screens too short to show it all.
- Kiri is now free and open source under the MIT or Apache 2.0 license.
