- **Side by side** (View ▸ Split Editor, ⌘\): two tabs of a window next to each other, or a Markdown or SVG file's text beside its preview (⌥⌃⌘P). ⌥-click a file or tab, press ⌥↩, or drag a tab to a side to open it there.
- **Custom keyboard shortcuts** (Settings ▸ Shortcuts): search every command, click its key and type a new one. Kiri warns when a key is taken and lets you reset one or all of them.
- **Pictures from elsewhere** (Settings ▸ Privacy): pictures and media in a Markdown preview that come from the internet or from outside the file's folder wait until you accept them in a notice at the top of the preview. Set it to Ask, Always Deny or Always Allow.
- A link in the Markdown preview that would open another app, a file in another app or a program now asks first. Web pages, mail addresses and text files open as before.
- Raw HTML in a Markdown file still shows in the preview, but no longer brings its own styles or forms.
- A broken archive shows a message instead of crashing Kiri.
