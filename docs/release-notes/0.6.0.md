- **Side by side** (View ▸ Split Editor, ⌘\): two tabs of a window next to each other, or a Markdown or SVG file's text beside its preview (⌥⌃⌘P). ⌥-click a file or tab, press ⌥↩, or drag a tab to a side to open it there.
- **Custom keyboard shortcuts** (Settings ▸ Shortcuts): search every command, click its key and type a new one. Kiri warns when a key is taken and lets you reset one or all of them.
